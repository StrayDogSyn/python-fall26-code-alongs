Use the linked primary documentation when answering a version-specific question. These materials are teaching examples, not a service integration or a public API recommendation.

- [Python http.server documentation](https://docs.python.org/3/library/http.server.html): the temporary loopback service used only for teaching.
- [LeetCode 1436](https://leetcode.com/problems/destination-city/description/): directed-pair input and the unique terminal-city guarantee.
