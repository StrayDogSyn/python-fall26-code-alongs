| Time | Phase | Plan | Failure to plan for |
| --- | --- | --- | --- |
| 0 to 10 min | Check-in | Revisit a Week 3 loop, then ask what you would store for a class roster. | Learners name only a list; ask which tasks need lookup by name or no repeats. |
| 10 to 25 min | I Do | Predict a collection for each task, then trace the roster list, score dictionary and meeting-time tuple. | Collections are treated as interchangeable; ask which property each row needs. |
| 25 to 40 min | We Do | Sort, rank and slice scores; break ties by name. | Tie order surprises learners; show the sort key includes the name. |
| 40 to 55 min | We Do | Write a file round trip with `open`, then repair the `"w"` overwrite. | The file holds only the last write; trace each open and say what `w` does. |
| 55 to 70 min | We Do, then pair | Read, parse and keep UTF-8, then repair the loop that removes items while visiting a list. | A skipped item after `remove`; trace indices after the first removal. |
| 70 to 83 min | You Do | Start `unique_names`, `highest_score` and `save_names`, run `python lp02-data-structures/check.py`, then try a Build exercise. | File checks seem to touch real files; they use temporary folders. |
| 83 to 90 min | Exit check | Answer the deck quiz and say list, dictionary, set and tuple once more. | If a learner answers from memory, ask for a collection choice for a new task. |
