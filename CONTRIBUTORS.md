## How credit works on GitHub here

The Contributors list in the repository sidebar is built from commit authors and `Co-authored-by` trailers whose email addresses belong to GitHub accounts. A tool with no GitHub account cannot appear there, and this repository does not invent addresses to make it so. This file and the hub footer are the record of credit. If a collaborator ever has a verified GitHub identity, add its `Co-authored-by` trailer to its commits and the sidebar will follow.

## Adding a credit
